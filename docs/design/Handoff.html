Global rules
  • × on any of SCR 02–04 → navigation.popToTop() with a confirm dialog if any progress is logged.
  • Swipe back gesture disabled inside lesson flow (gestureEnabled: false) so users do not lose progress by accident.
  • Voltooid → Volgende les calls replace with the next Intro; Klaar calls popToTop() back to Home.
  • Animations: slide_from_right (iOS-style) for all push transitions; for intro → study use fade (340ms cubic-bezier 0.4, 0, 0.2, 1).

Architecture rules

  • Feature folders: src/features/lesson/{components,hooks,api,types} — everything local. Cross-feature deps go through src/shared only.
  • No styled-components: StyleSheet.create + theme object via the useTheme() hook (reads from ThemeProvider).
  • Server data — through React Query only. UI state — through Zustand only. Do not mix.
  • Animations — Reanimated worklets only, no Animated.timing from RN core. All pressables — Pressable + scale-spring.
  • Accessibility: accessibilityLabel is required on every Pressable. Minimum touch target 44×44 dp.
  • Performance: memo for list items; FlashList instead of FlatList for lists with >20 items.
  • Errors: ErrorBoundary at the root + per-screen; onError reports to Sentry with context.

Accessibility

  • Contrast — WCAG AA on every text node (fg on bg = 14.2:1; fg-dim on bg = 8.8:1 ✅).
  • Dynamic Type: support iOS Larger Text — typography scales via PixelRatio.getFontScale() clamped to (0.85, 1.4).
  • VoiceOver/TalkBack: flashcard announces "Dutch phrase: …; tap to reveal English translation".
  • Reduce Motion: disable the flip animation (instant switch) and the wrong-answer letter shake.
  • Information-carrying icons get an accessibilityLabel; decorative ones use accessibilityElementsHidden.

Localization

UI is always in Dutch (part of the immersion methodology). Hints, errors, system copy — also NL with an EN fallback. Tutorial/onboarding has EN and UK variants. File structure: src/i18n/{nl,en,uk}/common.json.

  • Token storage — expo-secure-store (Keychain / EncryptedSharedPreferences).
  • API: HTTPS only; pinned certificate in production builds.
  • Right to erase — button in /settings: DELETE /api/v1/me with confirm dialog.

1. create features/foo/FooScreen.tsx
2. register in navigation/RootStack.tsx
3. type the params in navigation/types.ts

## Design system rules
- No raw colors — use theme.colors.* only
- No magic numbers — use theme.spacing.* only
- Font everywhere — Urbanist (preloaded in App.tsx)
- Buttons — through <Button> only; do not write a bespoke Pressable with a background fill

Key code — FlipCard.tsx

import Animated, { useSharedValue, useAnimatedStyle, withTiming, Easing } from 'react-native-reanimated';
import { useTheme } from '@/theme/useTheme';

type Props = { flipped: boolean; front: ReactNode; back: ReactNode; onPress?: () => void };

export default function FlipCard({ flipped, front, back, onPress }: Props) {
  const t = useTheme();
  const rot = useSharedValue(0);

  React.useEffect(() => {
    rot.value = withTiming(flipped ? 180 : 0, {
      duration: t.motion.flip,
      easing: Easing.bezier(0.4, 0, 0.2, 1),
    });
  }, [flipped]);

  const frontStyle = useAnimatedStyle(() => ({
    transform: [{ perspective: 1200 }, { rotateY: `${rot.value}deg` }],
    backfaceVisibility: 'hidden',
  }));
  const backStyle = useAnimatedStyle(() => ({
    transform: [{ perspective: 1200 }, { rotateY: `${rot.value + 180}deg` }],
    backfaceVisibility: 'hidden',
  }));

  return (
    <Pressable onPress={onPress} accessibilityLabel="Flashcard. Tap to reveal translation">
      <Animated.View style={[styles.face, frontStyle]}>{front}</Animated.View>
      <Animated.View style={[styles.face, backStyle, { position: 'absolute', inset: 0 }]}>{back}</Animated.View>
    </Pressable>
  );
}

REST endpoints (v1)

Offline-first strategy

  • Seed content (lessons + phrases JSON) is bundled into the APK/IPA — the app works offline.
  • Progress is saved to MMKV immediately; POST to backend happens in the background via a mutation queue (TanStack Query persister).
  • Audio: on entering Intro, pre-fetch all lesson MP3s → cached in FileSystem.documentDirectory + 'audio/'.
  • Conflict resolution: latest updatedAt wins; on tied timestamps server wins (rare).
